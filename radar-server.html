Radar Server Data Pipeline

Senior Project — Susitronix Partnership · Ultra96v2 Arm64 · Rust · 2023–2024

Overview

A dual-mode (Server/Archiver) radar data pipeline built for Professor John Mower's radar system at Western Washington University, in partnership with Susitronix. The system sources radar data — from hardware, simulated sources, or sample files — and streams it at high throughput over ZeroMQ. The Archiver mode subscribes to the Server's data stream, persists it to HDF5, forwards live data to clients, and serves historical data on demand.

Rust ZeroMQ HDF5 Arm64 Systems Programming

Architecture & Modes

The binary runs in three modes via CLI flags:

  • Dummy Server (--dummy) — Generates simulated radar data (configurable delay, packet structure) and publishes via ZeroMQ PUB socket. Includes a settings DEALER channel for runtime configuration from the Archiver.
  • Archiver (--archive) — Subscribes to the Server's data stream (ZMQ SUB), writes each packet to an HDF5 file, forwards live data to clients via ZMQ PUB, serves archived data on request via ZMQ ROUTER, and manages settings for both servers and clients via ZMQ ROUTER/DEALER.
  • Server (--server) — (Not yet implemented) Intended to source real radar hardware data, handle radar control commands from authorized clients, and implement radar blanking.

The plugins module organizes core logic:

  • source_data — traits and structs for data sourcing (simulated, hardware, archived)
  • publish_data — ZeroMQ connection management (Server, Subscriber, SettingsChannel traits)
  • radar_packet — packet structures (ComPacket, HDF5Packet, SettingsPacket, Identity, State) and HDF5 serialization traits

Qt Visualization Client

A separate Qt-based desktop client for radar visualization exists in a private repository. My involvement was limited to code review.

Project Status

Functional for Dummy Server and Archiver modes. The project was passed to a new team after graduation for continued development (real hardware integration, radar control commands, security hardening, and true Server mode).

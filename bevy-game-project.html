Bevy Game Project

Solo Project · Rust · Bevy · Avian Physics · Early Prototype · Desktop

Overview

A story-based isometric game built with the Bevy game engine in Rust. The original concept blends Stardew Valley's cozy life simulation, Disco Elysium's narrative depth and dialogue systems, and Monster Hunter's combat progression — scoped for solo development. Currently in early prototype phase with core physics and level systems implemented.

Rust Bevy ECS Avian Physics Isometric Story-Driven

My Contributions

As the sole developer, I have designed and implemented the following core systems:

  • Physics Integration with Avian — Set up the Avian physics engine, including collider mapping for isometric tile-based environments, rigid body configuration, and collision layers for player/enemy/environment interactions.
  • Level Deconstruction & Construction System — Built a system to fully serialize and deserialize levels, handling resource loading, scene management, ECS entity spawning/despawning, and UI interaction for level editing. Supports hot-reloading of level data during development.

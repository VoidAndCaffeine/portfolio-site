ToyOS

CSCI 447 — Operating Systems · Western Washington University · Dr. Phil Nelson

Overview

ToyOS is a complete x86 teaching operating system built from skeleton code over the course of a semester. The project implements a functional kernel with virtual memory management, a hierarchical filesystem, process scheduling and lifecycle management, synchronization primitives (mutexes, condition variables), a system call interface, and a user-space C runtime library. The system runs on QEMU and supports a suite of user-space programs including a shell, file utilities, and stress tests.

My Contributions

The following subsystems were designed and implemented by me (excluding professor-provided scaffolding and boilerplate):

  • Terminal Driver — Interrupt-driven character I/O with buffered read/write, line editing (Ctrl-H, Ctrl-U), and syscall integration.
  • Pipe Subsystem — Pipe creation, circular buffer management, NumToRead tracking, pipe sets for select()-style multiplexing, and dup syscall support.
  • Filesystem Syscalls — Implemented open_dir, read_dir, and directory traversal logic for the VFS layer.
  • Process Lifecycle — join, exit, clone fixes (copy-on-write semantics), and exec syscall with argument copying.
  • Trap & Exception Handling — Page fault resolution (including cause 12 handling), context save/restore, and syscall entry/exit trampolines in assembly.
  • Synchronization Fixes — Mutex scoping in the FCB layer, buffer circularization bugs, and race condition elimination in resource management.
